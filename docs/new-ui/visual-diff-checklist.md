# 视觉差异清单（对照基准图）


基准图（老UI）vs 新UI v1 差异清单：
1. ✅ 页眉：老UI有QQ头像+昵称（左上），新UI没有——这是用户信息，P3 接入（登录后才有）
2. ✅ 左侧栏：老UI顶部有图标logo（主页图标带图），新UI纯文字——加图标
3. ✅ 菜单树：老UI"总览"在搜索框正下且无箭头（当前页），其余带▶箭头；新UI"总览"有高亮底色 ✓但箭头样式待对齐

8. ⚠️ 字体：老UI微软雅黑，新UI默认无衬线——需显式声明
